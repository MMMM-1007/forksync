设置

公开仓库只需 public_repo 权限；私有仓库需要 repo。 生成地址：github.com/settings/tokens
token 只保存在本机 config.json（权限 600），不会上传到任何地方。
自动同步在服务进程内运行，关掉窗口不影响；进程退出后停止。想完全无人值守，可用任务计划程序常驻运行本程序。
🛡 删除保护
保护名单里的文件一旦出现在「上游要删除」的列表里，无论上面选什么都会被拦下。 例如填 \.md$ 就表示所有 markdown 文档都不许被同步删掉。

项目设置

本地模式需要本机安装 git，并已把仓库 clone 到该路径。API 模式不需要本地仓库，但不会同步 tag 与其他分支。
